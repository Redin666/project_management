# Митинги команды

Здесь фиксируются встречи и обсуждения, относящиеся к выполнению практики.

Для каждого митинга рекомендуется указывать:
- дату;
- участников;
- длительность;
- тему;
- принятые решения;
- созданные по итогам задачи.

Митинги также учитываются как работа по проекту и при необходимости заводятся отдельными Issues.
