## Фаза 1. Выбор концепции

Нужно:
1. придумать не менее 4 концепций;
2. сформулировать не менее 4 критериев;
3. получить трёхточечные экспертные оценки от каждого участника;
4. выполнить нечёткий коллективный TOPSIS;
5. выполнить чёткий коллективный МАИ;
6. сравнить результаты и выбрать концепцию.

## Задание 1. Сценарии использования

Для выбранной концепции необходимо:
1. определить акторов;
2. сформировать примерно 10–15 основных Use Cases;
3. построить Use Case Diagram;
4. для каждого Use Case построить Activity Diagram;
5. в Activity Diagram использовать swimlanes для разделения действий акторов/объектов.

## Правило декомпозиции

Крупные этапы не заводятся одной задачей. Каждый этап разбивается на отдельные Issues: анализ, подготовка данных, расчёты, диаграммы, проверки, оформление, митинги и другие виды работы.
