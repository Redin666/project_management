## 1️⃣ Фаза 1 — Выбор концепции проекта

### Суть фазы

На первом этапе команда должна выбрать концепцию небольшого программного проекта, с которой будет работать дальше на протяжении остальных фаз.

Для этого необходимо:

- придумать не менее **4 концепций программного проекта**;
- сформулировать не менее **4 критериев оценки**;
- каждому участнику дать экспертные оценки важности критериев и альтернатив;
- упорядочить три оценки как **пессимистичную, ожидаемую и оптимистичную**;
- определить лучший вариант методом **нечёткого коллективного TOPSIS**;
- определить лучший вариант методом **чёткого коллективного МАИ**;
- сравнить полученные результаты и сформулировать итоговый вывод.
