# Декомпозиция работ Фазы 3

## Основание

Для дальнейшей работы используется выбранная в Фазе 1 концепция:

**A1 — «Система управления результатами тестирования на проникновение».**

Фаза 2 начинается с декомпозиции работ Фазы 3. Полученные задачи используются как объекты экспертной оценки трудоёмкости, оценки предпочтений и последующего оптимального распределения.

## Правило назначения

На этом этапе задачи **не закрепляются за участниками вручную**.

Сначала для P3-01…P3-08 необходимо получить:

- согласованную трудоёмкость;
- три набора индивидуальных предпочтений.

После этого задача распределения решается в рамках Фазы 2. Полученный результат переносится в Assignee соответствующих GitHub Issues и в RACI.
