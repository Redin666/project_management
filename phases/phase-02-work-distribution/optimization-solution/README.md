## Переменная решения

Для каждой задачи `i` и участника `j` используется бинарная переменная:

`x[i,j] = 1`, если задача назначена участнику; иначе `0`.

## Целевая функция

Максимизируется суммарная предпочтительность назначенных задач:

`max Σ p[i,j] · x[i,j]`

где `p[i,j]` — индивидуальная оценка предпочтительности задачи.

## Ограничения

1. Каждая задача назначается ровно одному основному исполнителю.
2. Каждый участник получает от 2 до 3 основных задач.
3. Суммарная трудоёмкость участника находится в диапазоне от **4.0 до 5.5 ч**.
4. Все переменные назначения бинарные.
