# P2-05 — Решение задачи распределения

## Статус

✅ Оптимизационная модель реализована в **Pyomo** и решена оптимизатором **HiGHS**.

## Основание

Реализована формальная постановка из [P2-04](../optimization-formulation/README.md):

- бинарные переменные назначения `x[i,j]`;
- цель — максимизация суммарной предпочтительности;
- каждая задача назначается ровно одному основному исполнителю;
- каждому участнику назначается от 2 до 3 основных задач;
- нагрузка каждого участника ограничена диапазоном 4.0–5.5 ч.

## Инструмент

Использован **Python + Pyomo + HiGHS**.

Файлы:

- [solve_distribution.py](solve_distribution.py) — модель Pyomo;
- [requirements.txt](requirements.txt) — зависимости;

- [P2-05_Распределение_работ.xlsx](P2-05_Распределение_работ.xlsx) — расчётная книга;
- [GitHub Actions workflow](../../../.github/workflows/p2-pyomo.yml) — воспроизводимая автоматическая проверка.

## Проверка ограничений

- 8 из 8 задач назначены;
- каждая задача имеет одного основного исполнителя;
- количество задач на участника: **3 / 3 / 2**;
- допустимый диапазон: **2–3**;
- нагрузка: **5.5 / 4.5 / 4.5 ч**;
- допустимый диапазон нагрузки: **4.0–5.5 ч**;
- суммарная трудоёмкость: **14.5 ч**;
- все ограничения выполнены.
