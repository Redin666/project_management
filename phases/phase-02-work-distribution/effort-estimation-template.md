# Экспертная оценка трудоёмкости задач Фазы 3

## Метод

Для организационной оценки используется независимая оценка чистого рабочего времени с последующим согласованием.

Каждый участник сначала заполняет свою оценку **самостоятельно**, затем команда обсуждает различия и фиксирует итоговое значение.

## Правила

- оценивается **чистое рабочее время**, а не календарная длительность;
- оценки участников не копируются друг у друга до первичного заполнения;
- при существенном расхождении обсуждаются причины;
- в оптимизационную модель передаётся согласованная итоговая оценка.
