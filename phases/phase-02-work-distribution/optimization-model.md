# Постановка задачи распределения

## Назначение

После получения трудоёмкости задач и индивидуальных предпочтений необходимо определить распределение P3-01…P3-08 между тремя участниками.

## Обозначения

- i — задача Фазы 3;
- j — участник команды;
- e_i — согласованная трудоёмкость задачи i;
- p_ij — предпочтительность задачи i для участника j;
- x_ij ∈ {0,1} — назначена ли задача i участнику j;
- L_j — суммарная трудоёмкость работ участника j.

## Базовые ограничения

Каждая задача назначается ровно одному основному исполнителю:

`Σ_j x_ij = 1`.

Нагрузка участника:

`L_j = Σ_i e_i · x_ij`.

При необходимости вводится ограничение, что каждый участник получает хотя бы одну основную задачу.

## Рекомендуемая цель

Можно совместить два требования:

1. участникам по возможности назначаются предпочитаемые задачи;
2. нагрузка между участниками остаётся разумно сбалансированной.

Один из вариантов — максимизировать суммарную предпочтительность и одновременно штрафовать отклонение нагрузки от средней.

Окончательная формулировка, коэффициенты и ограничения фиксируются командой после получения реальных оценок.

## Инструмент

Допустимо использовать Pyomo, OpenSolver, NEOS или другой подходящий инструмент.

Для репозитория рекомендуется сохранить:

- входные данные;
- код или модель;
- найденное распределение;
- значение целевой функции;
- проверку выполнения ограничений;
- краткое объяснение результата.
