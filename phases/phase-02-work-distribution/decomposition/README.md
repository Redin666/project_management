# Декомпозиция работ Фазы 3

## Основание

Выбранная в Фазе 1 концепция:

**A1 — «Система управления результатами тестирования на проникновение».**

## Рабочие пакеты

| Код | Задача | Ожидаемый результат | Зависимость | Основной исполнитель |
|---|---|---|---|---|
| **P3-01** | Сформировать 10–15 Use Cases и определить границы проекта | Акторы, Use Cases, основные, альтернативные и негативные сценарии | — | **Никита Редин** |
| **P3-02** | Выполнить COSMIC Function Points | Функциональные процессы, Entry/Exit/Read/Write, итог CFP | P3-01 | **Никита Редин** |
| **P3-03** | Выполнить Use Case Points | UAW, UUCW, TCF, ECF, UCP и трудозатраты | P3-01 | **Павел Шатков** |
| **P3-04** | Провести коллективную экспертную оценку | Согласованные оценки Use Cases / Stories / Slices | P3-01 | **Никита Редин**, участвуют все |
| **P3-05** | Агрегировать экспертные оценки | Итоговая коллективная оценка проекта | P3-04 | **Павел Шатков** |
| **P3-06** | Сопоставить COSMIC, UCP и экспертную оценку | Сводная таблица и аналитический вывод | P3-02, P3-03, P3-05 | **Владислав Полищук** |
| **P3-07** | Оценить размер команды, компетенции и срок | Состав команды, роли, специальные требования, срок | P3-06 | **Павел Шатков** |
| **P3-08** | Определить кандидатов на исключение и оформить выводы | Менее важные, но тяжёлые функции + итоговый вывод | P3-06, P3-07 | **Владислав Полищук** |

## Принцип распределения

- Никита ведёт Use Cases, COSMIC и организацию коллективной экспертной оценки.
- Павел отвечает за UCP, агрегацию коллективных трудозатрат и оценку состава команды/срока.
- Владислав сопоставляет методы и оформляет итоговый анализ сокращения функциональности.
- P3-04 выполняется всей командой, поскольку по заданию требуется коллективная экспертная оценка.

Распределение считается рабочим организационным планом и проверяется оптимизационной моделью Фазы 2.
