# Фаза 2 — Распределение работы

## Статус

🟡 В работе.

## Цель

Подготовить и выполнить распределение работ **Фазы 3 — Оценка проекта** между участниками команды на основе экспертной оценки трудоёмкости, индивидуальных предпочтений и формальной оптимизационной модели.

Фаза 2 выполняется перед основной работой Фазы 3, поэтому организационная декомпозиция и ответственные за блоки определены заранее, а решение оптимизационной модели используется как проверка и при необходимости корректировка распределения.

## Выбранный проект

В Фазе 1 выбрана концепция:

**A1 — «Система управления результатами тестирования на проникновение».**

Именно её масштаб и трудозатраты будут оцениваться в Фазе 3.

## Экспертная оценка трудоёмкости

Шаблон: [effort-estimation-template.md](effort-estimation-template.md).

Порядок работы:

1. каждый участник независимо оценивает чистое время P3-01…P3-08;
2. оценки сравниваются;
3. расхождения обсуждаются;
4. команда фиксирует согласованную оценку;
5. согласованные значения передаются в оптимизационную модель.

## Индивидуальные предпочтения

Шаблоны находятся в каталоге [preferences](preferences/README.md).

Каждый участник независимо оценивает предпочтительность каждой задачи по шкале **1–5**:

- 1 — крайне нежелательно;
- 2 — низкая предпочтительность;
- 3 — нейтрально;
- 4 — предпочтительно;
- 5 — очень желательно.

## Оптимизационная модель

Черновая постановка: [optimization-model.md](optimization-model.md).

Модель должна учитывать:

- трудоёмкость каждой задачи;
- индивидуальные предпочтения;
- назначение каждой задачи одному основному исполнителю;
- разумный баланс нагрузки;
- участие всех трёх членов команды.

Текущее организационное распределение используется как рабочий план. После решения модели команда сравнивает рассчитанное распределение с плановым и при необходимости корректирует Assignee Фазы 3.

## Результаты Фазы 2

По завершении должны быть получены:

- декомпозиция P3-01…P3-08;
- оценки трудоёмкости;
- три набора предпочтений;
- математическая постановка;
- решение оптимизационной модели;
- подтверждённое или скорректированное распределение Фазы 3;
- обновлённый RACI;
- оформленный итог Фазы 2.
