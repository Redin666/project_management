# Фаза 2 — Распределение работы

![Прогресс](https://img.shields.io/badge/Прогресс-0%25-lightgrey)

## Цель

Распределить работы третьей фазы между участниками команды на основе трудоёмкости и личных предпочтений.

## Что нужно сделать

- сначала декомпозировать работы фазы 3 на отдельные задачи;
- оценить сложность или трудозатраты каждой задачи экспертным методом;
- каждому участнику дать индивидуальные оценки предпочтительности задач;
- сформулировать задачу распределения: целевую функцию и ограничения;
- решить задачу с помощью подходящего инструмента;
- обосновать полученное распределение.

## Связь с фазой 3

Эта фаза выполняется до основной работы по фазе 3, потому что именно здесь формируется набор задач, которые затем распределяются между участниками.

## Результаты фазы

- перечень задач фазы 3;
- оценки трудоёмкости;
- матрица предпочтений;
- математическая постановка задачи;
- найденное распределение;
- краткое обоснование решения.
