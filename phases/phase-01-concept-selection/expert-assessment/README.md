# Экспертное оценивание

## Назначение

Для нечёткого коллективного TOPSIS используются **три независимые оценки** каждого показателя — по одной от каждого участника команды:

- Никита Редин Андреевич (@Redin666);
- Шатков Павел Вадимович (@Papla2016);
- Полищук Владислав (@VladPolishuk).

Каждый эксперт выставляет **одно целое значение от 0 до 10** для важности каждого критерия и для каждой альтернативы по каждому критерию.

После этого три оценки упорядочиваются и формируют треугольное нечёткое число:

`(l, m, u) = (MIN, MEDIAN, MAX)`.

Для benefit-критериев нижняя граница соответствует более пессимистичной оценке, верхняя — более оптимистичной. Для cost-критериев числовой порядок тот же, но меньшая оценка означает меньшие затраты и поэтому является более благоприятной.

> **Статус оценок:** ниже подготовлен расчётный черновик. Перед окончательным закрытием issue #15 каждый участник должен подтвердить либо скорректировать свою колонку. Это нужно, потому что экспертные оценки должны отражать личное мнение участников, а не автоматически сгенерированные значения.

## Принцип формирования коллективной оценки

Для любого критерия или пары «альтернатива–критерий» используются три значения `x1, x2, x3`:

```
l = MIN(x1, x2, x3)
m = MEDIAN(x1, x2, x3)
u = MAX(x1, x2, x3)
```

Так сохраняются нижняя граница, центральное значение и верхняя граница мнений команды.
