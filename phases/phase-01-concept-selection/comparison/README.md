# Сравнение результатов TOPSIS и МАИ

## Цель

Сопоставить ранжирования концепций A1–A4, полученные нечётким коллективным TOPSIS и чётким коллективным МАИ, оценить их согласованность и сформулировать итоговый выбор концепции для следующих фаз.

## Исходные данные

- [Результаты нечёткого коллективного TOPSIS](../topsis/README.md) — [CSV](../topsis/topsis-results.csv)
- [Результаты чёткого коллективного МАИ](../mai/README.md) — [CSV](../mai/mai-results.csv)
- [Концепции A1–A4](../concepts/README.md), [критерии K1–K7](../criteria/README.md)

## Кратко о методах

| | Нечёткий коллективный TOPSIS | Чёткий коллективный МАИ |
|---|---|---|
| Исходные суждения | Оценки 0–10 важности критериев и альтернатив | Попарные сравнения по шкале Саати |
| Агрегирование мнений трёх экспертов | Треугольное число `(MIN, MEDIAN, MAX)` | Поэлементное геометрическое среднее матриц |
| Учёт benefit / cost | Разные формулы нормализации | Направление предпочтения при попарном сравнении |
| Итоговый показатель | Коэффициент близости `CC = D− / (D+ + D−)` | Глобальный приоритет `P(Aᵢ) = Σ w(Kₖ)·w(Aᵢ│Kₖ)` |
| Контроль качества | — | Согласованность `CR ≤ 0,10` (макс. ≈ 0,0292) |

## Анализ согласованности

- **Ранжирования полностью совпадают:** A1 > A4 > A3 > A2 в обоих методах; разница мест для всех концепций равна 0.
- Коэффициент ранговой корреляции Спирмена `ρ = 1 − 6·Σd² / (n(n²−1)) = 1 − 0 = 1,00`, коэффициент Кендалла `τ = 1,00`.
- **Лидер устойчив.** Отрыв A1 от второго места: по TOPSIS ΔCC = 0,0429 (≈ 8 %), по МАИ ΔP = 0,0387 (≈ 15 %).
- **Аутсайдер устойчив.** A2 последняя в обоих методах: высокий потенциал развития (K3) не компенсирует наибольших затрат и внешних зависимостей (K5–K7).
- **Неустойчивая пара A4 / A3.** В TOPSIS разрыв заметен (ΔCC = 0,0765), а в МАИ минимален (ΔP ≈ 0,0005). Порядок этих концепций может измениться при корректировке суждений, но на выбор лидера это не влияет.
- Различие в «плотности» МАИ объясняется тем, что геометрическое среднее попарных сравнений сглаживает крайние оценки, а TOPSIS сильнее реагирует на границы нечётких чисел (пессимистичную и оптимистичную оценки).

## Ограничения

- Попарные матрицы МАИ предварительно восстановлены из тех же оценок 0–10, что используются в TOPSIS. Поэтому методы не полностью независимы, и совпадение рангов частично обусловлено общим источником данных.
- Экспертные оценки остаются черновыми до подтверждения участниками ([issue #15](https://github.com/Redin666/project_management/issues/15)). После подтверждения Excel-книги пересчитываются автоматически, и сравнение нужно повторить.

## Вывод

Оба метода многокритериального анализа единогласно определили лидером концепцию **A1 — «Система управления результатами тестирования на проникновение»** (CC = 0,5498; P = 0,2909). Второе место занимает A4, третье — A3, четвёртое — A2; полное совпадение ранжирований (ρ = 1) подтверждает обоснованность выбора.

**Концепция A1 принимается для дальнейшей работы в Фазах 2–5.**
