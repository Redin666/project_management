# Фаза 1 — Выбор концепции проекта

![Прогресс](https://img.shields.io/badge/Прогресс-0%25-lightgrey)

## Цель

Выбрать концепцию компактного программного проекта, которая будет использоваться в следующих фазах.

## Что нужно сделать

- придумать не менее 4 концепций;
- сформулировать не менее 4 критериев оценки;
- каждому участнику оценить важность критериев и альтернативы;
- упорядочить три оценки как пессимистичную, ожидаемую и оптимистичную;
- выполнить нечёткий коллективный TOPSIS;
- выполнить чёткий коллективный МАИ;
- сравнить результаты и сформулировать вывод.

## Результаты фазы

Здесь будут храниться:
- описания концепций;
- критерии;
- экспертные оценки;
- расчёты TOPSIS;
- расчёты МАИ;
- итоговое сравнение и выбранная концепция.

## Задачи

Конкретные работы ведутся через GitHub Issues. Для каждой задачи фиксируются исполнитель, период работы, плановые и фактические трудозатраты.
