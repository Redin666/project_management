# A2 — Система контроля безопасности процесса разработки ПО

## Назначение

Система предназначена для контроля проблем безопасности, обнаруживаемых в процессе разработки программного обеспечения.

## Основная идея

Результаты SAST, DAST и SCA собираются в одном месте. Найденные проблемы классифицируются, назначаются разработчикам и отслеживаются до исправления и повторной проверки.

## Предполагаемые пользователи

- специалист DevSecOps;
- разработчик;
- руководитель проекта или команды разработки.

## Примеры функций

- добавление проекта;
- регистрация сборки;
- импорт результатов SAST;
- импорт результатов DAST;
- импорт результатов SCA;
- регистрация проблемы безопасности;
- назначение приоритета;
- назначение разработчика;
- изменение статуса;
- отметка ложного срабатывания;
- повторная проверка;
- поиск и фильтрация;
- просмотр статистики.
