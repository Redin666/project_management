# A4 — Система управления проверками защищённости информационных систем

## Назначение

Система предназначена для организации проверок защищённости информационных систем и контроля устранения выявленных несоответствий.

## Основная идея

Специалист создаёт проверку информационной системы, формирует или выбирает чек-лист, отмечает результаты проверки требований и регистрирует выявленные несоответствия. Для них назначаются ответственные и контролируются сроки устранения.

## Предполагаемые пользователи

- специалист по информационной безопасности;
- аудитор;
- ответственный за информационную систему.

## Примеры функций

- создание проверки;
- выбор объекта проверки;
- формирование чек-листа;
- фиксация результата проверки требования;
- регистрация несоответствия;
- назначение критичности;
- назначение ответственного;
- добавление подтверждающих материалов;
- изменение статуса;
- повторная проверка;
- поиск и фильтрация;
- просмотр статистики;
- формирование отчёта.

Концепция подходит для дальнейшей декомпозиции примерно на 10–15 Use Cases.
