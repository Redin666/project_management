# Концепции проекта

В рамках Фазы 1 команда рассматривает четыре альтернативные концепции программного проекта в области информационной безопасности.

| № | Концепция | Направление |
|---|---|---|
| **A1** | [Система управления результатами тестирования на проникновение](01-pentest-management.md) | Pentest |
| **A2** | [Система контроля безопасности процесса разработки ПО](02-devsecops-security.md) | DevSecOps |
| **A3** | [Система регистрации и обработки инцидентов информационной безопасности](03-soc-incidents.md) | SOC |
| **A4** | [Система управления проверками защищённости информационных систем](04-security-audit.md) | Security Audit |

Эти четыре альтернативы будут сравниваться по общему набору критериев с использованием экспертных оценок, нечёткого коллективного TOPSIS и коллективного МАИ.
