**Проверка направления сценариев:**
- Benefit: пессимистичная ≤ ожидаемая ≤ оптимистичная.
- Cost: пессимистичная ≥ ожидаемая ≥ оптимистичная.

Для нечёткого числа `(l, m, u)` значения численно сортируются по возрастанию; для cost при этом оптимистичная оценка оказывается первой.
