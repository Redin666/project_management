# Чёткий коллективный метод анализа иерархий (МАИ)

## Цель

Сравнить четыре концепции проекта по **семи общим критериям** методом чёткого коллективного МАИ, построить матрицы попарных сравнений, получить веса критериев и локальные приоритеты альтернатив, рассчитать общий рейтинг и проверить согласованность суждений.

## Исходные данные

- [Четыре концепции A1–A4](../concepts/README.md)
- [Семь критериев K1–K7](../criteria/README.md)
- [Индивидуальные экспертные оценки](../expert-assessment/README.md)
- [Исходные значения для трёх участников (CSV)](../expert-assessment/expert-ratings.csv)

**Важно:** в текущих материалах нет отдельно собранных попарных сравнений МАИ. Поэтому книга содержит **предварительные матрицы**, восстановленные из опубликованных черновых оценок 0–10. Это расчётный пример, а не независимо подтверждённые оценки трёх экспертов. До окончательного выбора проекта эксперты должны проверить и при необходимости заменить каждое попарное суждение.

## Этап 1 — Подготовка индивидуальных матриц

Для каждого из трёх экспертов предусмотрены восемь матриц:

- одна **7×7**, отражающая важность критериев;
- семь **4×4**, сравнивающих четыре альтернативы по соответствующему критерию.

Для воспроизводимого чернового заполнения использовано следующее правило: при одинаковых баллах `a(i,j) = 1`; при разных баллах сила предпочтения `p = min(9, 1 + |xᵢ - xⱼ|)`.

Если объект i предпочтительнее j, `a(i,j) = p`, иначе `a(i,j) = 1/p`. Для **K1–K4 (benefit)** предпочтительнее большее значение, для **K5–K7 (cost)** предпочтительнее меньшее. Диагональ равна 1, обратная пара вычисляется формулой `a(j,i) = 1/a(i,j)`.

**Это только прозрачный способ предзаполнения**: выставлять напрямую суждения по шкале Саати методически предпочтительнее. В Excel жёлтые клетки содержат редактируемые значения прямых сравнений; обратные сравнения и результаты пересчитываются.

## Этап 2 — Коллективные попарные сравнения

Индивидуальные матрицы объединяются **поэлементным геометрическим средним**:

`aᵢⱼ(группа) = (aᵢⱼ(Редин) · aᵢⱼ(Шатков) · aᵢⱼ(Полищук))^(1/3)`.

Агрегирование сохраняет взаимную обратность матриц и учитывает мнения всех трёх участников.

## Этап 3 — Локальные приоритеты

Для каждой матрицы порядка `n` рассчитывается геометрическое среднее строки:

`gᵢ = (aᵢ₁ · ... · aᵢₙ)^(1/n)`.

Локальный вес определяется нормализацией:

`wᵢ = gᵢ / Σgⱼ`.

Для групповой матрицы критериев получаем **семь весов K1–K7**. Для каждой групповой матрицы альтернатив получаем **четыре локальных приоритета A1–A4**. Суммы весов каждой матрицы равны единице.

## Этап 4 — Проверка согласованности

Приближённое собственное значение вычисляется по весам геометрических средних строк:

`λmax ≈ (1/n) · Σ[(A·w)ᵢ / wᵢ]`.

Далее:

- `CI = max(0, (λmax - n) / (n - 1))`;
- `CR = CI / RI`;
- `RI = 0,90` для матрицы 4×4 и `RI = 1,32` для 7×7;
- приемлемая согласованность: **CR ≤ 0,10**.

В рабочем черновике максимальное `CR ≈ 0,0292` среди **24 индивидуальных и 8 коллективных матриц**. Низкое CR показывает внутреннюю согласованность *полученных матриц*, но **не заменяет подтверждения их содержания экспертами**.

## Этап 5 — Глобальные приоритеты

Общий приоритет альтернативы вычисляется как:

`P(Aᵢ) = Σₖ w(Kₖ) · w(Aᵢ | Kₖ)`.

Чем выше `P`, тем предпочтительнее альтернативный проект.

## Интерпретация

По текущему *предварительному* расчёту лидирует **A1 — управление результатами пентеста**. При этом разница между **A4 (0,252228)** и **A3 (0,251695)** крайне мала: около **0,000533**, поэтому их относительный порядок неустойчив к изменению суждений.

МАИ и TOPSIS используют один набор альтернатив и критериев, но разные способы вычисления предпочтений. Сопоставление их рейтингов и итоговое решение выполняются отдельным этапом после проверки исходных экспертных данных.

## Вывод

Расчётная схема коллективного МАИ реализована: подготовлены индивидуальные матрицы, получены групповые попарные оценки, локальные и глобальные приоритеты, контроль нормировки и проверка согласованности.

**Ограничение:** результат остаётся предварительным, поскольку попарные суждения не получены через независимый опрос экспертов. Для согласования окончательного результата необходимо подтвердить матрицы на листах каждого участника.
