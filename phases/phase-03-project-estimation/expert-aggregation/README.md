# P3-05 - Агрегирование экспертных оценок

## Цель и исходные данные

Получить оценку трудозатрат всего функционального объёма MVP проекта **«Система управления результатами тестирования на проникновение»** на основании коллективно согласованных оценок Use Cases из [P3-04](../expert-estimation/README.md).

Источник - [collective-estimation.csv](../expert-estimation/collective-estimation.csv). В P3-04 команда согласовала оценки **12 Use Cases** в человеко-часах. Для P3-05 берутся только значения `agreed_hours`: повторное усреднение голосов экспертов не выполняется, поскольку оценки уже согласованы командой.

## Способ агрегации

1. Каждый Use Case входит в расчёт ровно один раз с согласованной трудоёмкостью `h_i`.
2. Use Cases объединяются в четыре функциональные группы. Группировка нужна для анализа структуры трудозатрат, но не изменяет исходные оценки.
3. Трудоёмкость группы рассчитывается как сумма `H_группы = Σ h_i` для включённых в неё Use Cases.
4. Итоговая оценка проекта рассчитывается как `H_проекта = Σ H_группы = Σ h_i`. Доля группы - `H_группы / H_проекта × 100%`.
5. Выполняется контроль: **12 уникальных UC**, сумма всех строк совпадает с `TOTAL` исходного файла, а сумма групп - с итогом проекта.

Наличие зависимостей между UC не означает, что один и тот же Use Case нужно оценить повторно. Дополнительный коэффициент на зависимости, интеграцию или риски не вводится без отдельного обоснования.

## Распределение по функциональным группам

| Функциональная группа | Входящие Use Cases | Количество | Человеко-часы | Доля |
|---|---|---:|---:|---:|
| Проект и scope | UC-01, UC-02 | 2 | **10** | 14,71% |
| Находки и взаимодействие | UC-03, UC-04, UC-05, UC-06, UC-07, UC-10, UC-11 | 7 | **35** | 51,47% |
| Отчётность | UC-08, UC-09 | 2 | **18** | 26,47% |
| Пользователи и роли | UC-12 | 1 | **5** | 7,35% |
| **ИТОГО** | **UC-01 - UC-12** | **12** | **68** | **100,00%** |

Контроль арифметики: **10 + 35 + 18 + 5 = 68 человеко-часов**.

Подробная таблица по каждому UC с накопленным итогом - [aggregation.csv](aggregation.csv), машинно-читаемая сводка по группам - [group-summary.csv](group-summary.csv).

## Итоговая оценка и интерпретация

**Базовая суммарная коллективная экспертная оценка проекта - 68 человеко-часов.**

Среднее на один Use Case - **68 / 12 ≈ 5,67 ч**. Наиболее трудоёмкие элементы: **UC-08 (13 ч)**, **UC-03 (8 ч)** и **UC-11 (8 ч)**. В совокупности они дают **29 ч, или 42,65%** трудозатрат. Больше половины общей оценки (**35 ч, 51,47%**) приходится на управление находками и взаимодействие с ними.

Эта оценка относится к **реализации перечисленных 12 Use Cases в границах MVP**. Она не является подтверждённым бюджетом полного жизненного цикла: отдельный резерв на неопределённость, эксплуатацию, развёртывание и другие сквозные работы не оценивался. Не следует прибавлять к 68 ч трудоёмкость организационных задач Фазы 3 из P2-02 - это разные объекты оценки.

## Воспроизведение

Из данного каталога выполнить:

```bash
python3 aggregate.py
```

Скрипт без сторонних зависимостей читает согласованные оценки P3-04, сверяет идентификаторы с перечнем Use Cases и проверяет контрольную сумму. Затем формирует **aggregation.csv** и **group-summary.csv**.

В [расчётной книге Excel](P3-05_Агрегация_экспертных_оценок.xlsx) представлены построчные данные, накопленный итог, формулы группировки, контроль суммы и диаграмма. Числа в книге взяты из той же согласованной оценки P3-04.
