# Коллективная экспертная оценка трудозатрат

## Цель

Оценить трудозатраты Use Cases проекта **«Система управления результатами тестирования на проникновение»** коллективным экспертным способом и получить согласованные значения для последующей агрегации в оценку всего проекта.

## Метод

Использован формат **открытого экспертного обсуждения с достижением согласованности**.

Для каждого Use Case учитывались:

- количество шагов основного сценария;
- наличие альтернативных и негативных сценариев;
- число сущностей и связей;
- необходимость работы с файлами и доказательствами;
- сложность бизнес-логики;
- объём чтения и записи данных;
- требования к проверке прав доступа;
- необходимость формирования составного результата.

Для унификации использована дискретная шкала трудоёмкости:

**1, 2, 3, 5, 8, 13 часов.**

Итоговое значение по каждому Use Case фиксируется как согласованная оценка команды.

Наиболее трудоёмкие элементы:

Наименьшую трудоёмкость получили UC-05, UC-06 и UC-10 — по **3 ч**.

## Интерпретация

Основная нагрузка приходится на функции, где требуется объединять несколько типов данных или поддерживать сложное изменение состояния системы.

Формирование отчёта является самым тяжёлым Use Case, поскольку использует данные проекта, scope, находок и доказательств. Регистрация уязвимости и re-test также требуют большего объёма логики по сравнению с простыми операциями назначения, комментирования и прикрепления доказательств.
