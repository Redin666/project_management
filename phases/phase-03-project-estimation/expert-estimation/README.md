# Коллективная экспертная оценка — подготовка

## Назначение

Материалы подготовлены для P3-04. Организатор — Никита Редин, в оценивании участвуют все три члена команды.

## Что оцениваем

Оцениваются трудозатраты 12 Use Cases UC-01…UC-12 из каталога [use-cases](../use-cases/README.md).

## Предлагаемый метод

Для проекта используется упрощённый Planning Poker:

- каждый участник независимо выбирает оценку в часах из ряда: 1, 2, 3, 5, 8, 13;
- оценки открываются одновременно;
- если есть расхождение, участники с минимальной и максимальной оценкой объясняют причины;
- проводится повторная оценка;
- работа продолжается до достижения согласованного значения.

## Почему задача пока не закрывается

По заданию требуется **коллективная экспертная оценка**. Поэтому нельзя автоматически подставить за Никиту, Павла и Владислава три вымышленных мнения.

Организационная часть подготовлена, но итоговые значения должны быть получены от участников.
