# Use Cases — система управления результатами тестирования на проникновение

## Назначение

Материалы подготовлены для задачи P3-01 и используются как исходные данные для COSMIC Function Points, Use Case Points и коллективной экспертной оценки.

## Граница системы

В границы MVP входят:

- ведение проектов тестирования на проникновение;
- управление областью тестирования и активами;
- регистрация, изменение и повторная проверка уязвимостей;
- хранение доказательств;
- назначение ответственных;
- поиск и фильтрация результатов;
- формирование и экспорт отчёта;
- взаимодействие с представителем заказчика;
- управление пользователями и ролями.

Вне границ MVP: автоматическое сканирование инфраструктуры, непосредственное выполнение атак, SIEM/SOAR, биллинг и управление договорами.

## Акторы

| Актор | Роль |
|---|---|
| Пентестер | Регистрирует результаты, доказательства и выполняет повторную проверку |
| Руководитель проекта / тимлид | Создаёт проект, задаёт scope, назначает ответственных, формирует отчёт |
| Представитель заказчика | Просматривает доступные результаты и оставляет комментарии |
| Администратор | Управляет пользователями и ролями |
