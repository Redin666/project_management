# Фаза 3 — Оценка проекта

## Статус

🟠 Декомпозиция подготовлена. Выполнение начинается после завершения распределения в Фазе 2.

## Цель

Оценить масштаб выбранного проекта несколькими независимыми способами, сопоставить результаты и сделать выводы о команде, сроках и составе функциональности.

Выбранный проект:

**A1 — «Система управления результатами тестирования на проникновение».**

## Связь с Фазой 2

Перед выполнением Фазы 3 её работы оцениваются и распределяются в [Фазе 2](../phase-02-work-distribution/README.md).

Полная декомпозиция: [phase-03-task-decomposition.md](../phase-02-work-distribution/phase-03-task-decomposition.md).

Финальные Assignee задач P3-01…P3-08 будут установлены после решения оптимизационной задачи распределения.

## Работы Фазы 3

| Код | Работа |
|---|---|
| P3-01 | Сформировать не менее 10 Use Cases, включая альтернативные и негативные сценарии |
| P3-02 | Оценить проект в COSMIC Function Points |
| P3-03 | Оценить проект методом Use Case Points и получить ориентировочные трудозатраты |
| P3-04 | Провести коллективную экспертную оценку Use Cases или более мелких элементов |
| P3-05 | Агрегировать экспертные оценки в оценку всего проекта |
| P3-06 | Сопоставить COSMIC, UCP и коллективную экспертную оценку |
| P3-07 | Оценить необходимый размер команды, специальные компетенции и ориентировочный срок |
| P3-08 | Определить менее важные, но ресурсоёмкие функции, которые можно исключить, и оформить итоговые выводы |

## Результаты Фазы 3

По завершении должны быть получены:

- не менее 10 Use Cases;
- COSMIC Function Points;
- Use Case Points и производная оценка трудозатрат;
- коллективная экспертная оценка;
- сравнение результатов трёх подходов;
- вывод о масштабе проекта;
- оценка размера и состава команды;
- ориентировочный срок реализации;
- перечень функций-кандидатов на исключение.
