# Фаза 3 — Оценка проекта

![Прогресс](https://img.shields.io/badge/Прогресс-0%25-lightgrey)

## Цель

Оценить масштаб выбранного проекта несколькими независимыми способами и сопоставить результаты.

## Что нужно сделать

- набросать не менее 10 Use Cases;
- оценить проект в COSMIC Function Points;
- оценить проект в Use Case Points и приблизительно определить трудозатраты;
- провести коллективную экспертную оценку трудозатрат Use Cases или более мелких элементов;
- агрегировать экспертные оценки в оценку всего проекта;
- сравнить результаты разных методов;
- оценить примерный размер команды и срок реализации;
- определить функции, которыми можно пожертвовать при необходимости.

## Дополнительные UML-материалы

Use Cases и UML-диаграммы можно хранить внутри этой фазы, чтобы повторно использовать их при оценивании.

## Результаты фазы

- перечень Use Cases;
- COSMIC-оценка;
- Use Case Points;
- экспертная оценка;
- сравнительный анализ;
- выводы по масштабу проекта, команде и срокам.
