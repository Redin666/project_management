# P4-06 — Сравнение Монте-Карло моделей

| Модель | Средний срок | Медиана | P80 |
|---|---:|---:|---:|
| Throughput по числу задач | 4,022 нед. | 4 нед. | **5 нед.** |
| Человеко-часы + triangular | 9,810 нед. | 9 нед. | **13 нед.** |

Разница по P80 составляет **8 недель**.

Первая модель считает все задачи одинаковыми и отражает исторический темп закрытия Issues. Вторая учитывает неодинаковую длительность P5-задач и ограничивает работу доступной недельной мощностью. Поэтому она чувствительнее к неделям с низким объёмом зафиксированного рабочего времени.

Для осторожного планирования Фазы 5 используется **P80 = 13 недель**, а модель throughput служит сравнительной оценкой.
