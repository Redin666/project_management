# Фаза 4 — Прогнозирование

![Прогресс](https://img.shields.io/badge/Прогресс-0%25-lightgrey)

## Цель

Спрогнозировать длительность пятой фазы на основе статистики работы команды.

## Что нужно сделать

- сначала декомпозировать работы фазы 5;
- дать каждой задаче трёхточечную оценку времени;
- собрать статистику числа задач, выполнявшихся по неделям;
- построить Монте-Карло модель по недельному throughput;
- собрать статистику доступных человеко-часов по неделям;
- построить вторую Монте-Карло модель с треугольным распределением длительности задач;
- для обеих моделей определить срок выполнения с 80% достоверностью;
- сравнить результаты и объяснить различия.

## Связь с фазой 5

Эта фаза использует будущие задачи фазы 5 как входные данные для прогнозирования.

## Результаты фазы

- декомпозиция фазы 5;
- трёхточечные оценки;
- исходная статистика;
- две модели Монте-Карло;
- прогнозы сроков;
- сравнение моделей.
