# P4-04 — Монте-Карло по недельному throughput

## Модель

На каждой итерации сэмплируется число завершённых задач за очередную неделю из эмпирического ряда:

`[3, 0, 4, 2, 7, 4, 0, 3]`.

Симуляция продолжается, пока не будут завершены все **10 задач Фазы 5**.

Параметры:

- seed: 42;
- итераций: 100 000.

## Результат

- средний срок: **4,022 недели**;
- медиана: **4 недели**;
- **P80: 5 недель**;
- P90: 6 недель.

Следовательно, по модели throughput плановый срок с 80%-й уверенностью — **5 недель**.
