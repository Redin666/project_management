# P4-04 — Монте-Карло по недельному throughput

Эмпирическое распределение числа закрытых задач в неделю:

`[3, 0, 4, 2, 7, 4, 0, 3]`.

На каждой итерации сэмплируется недельный throughput до достижения 10 завершённых задач Фазы 5.

Параметры:
- seed = 42;
- 100 000 итераций.

## Результат

- средний срок: **4,022 недели**;
- медиана: **4 недели**;
- **P80 = 5 недель**;
- P90 = 6 недель.
