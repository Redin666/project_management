# P4-05 — Монте-Карло по человеко-часам

На каждой итерации:

1. длительность каждой P5-задачи сэмплируется из треугольного распределения по O/M/P;
2. суммируется требуемое чистое время;
3. недельная доступная мощность сэмплируется из истории зафиксированных человеко-часов:
   `[3, 0, 5, 0, 8.25, 0, 0, 2]`;
4. моделирование продолжается до накопления требуемого времени.

Параметры:
- seed = 42;
- 100 000 итераций.

## Результат

- средняя сэмплированная трудоёмкость: **19,499 ч**;
- средний срок: **9,810 недели**;
- медиана: **9 недель**;
- **P80 = 13 недель**;
- P90 = 15 недель.
