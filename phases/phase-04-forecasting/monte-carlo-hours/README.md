# P4-05 — Монте-Карло по человеко-часам

## Модель

На каждой итерации:

1. время каждой P5-задачи сэмплируется из треугольного распределения `(O, M, P)`;
2. суммарная требуемая трудоёмкость сравнивается с накопленной недельной мощностью;
3. недельная мощность сэмплируется из эмпирического ряда зафиксированных часов:
   `[3, 0, 5, 0, 8.25, 0, 0, 2]`.

Параметры:

- seed: 42;
- итераций: 100 000.

## Результат

- средняя сэмплированная трудоёмкость Фазы 5: **19,499 ч**;
- средний срок: **9,810 недели**;
- медиана: **9 недель**;
- **P80: 13 недель**;
- P90: 15 недель.
