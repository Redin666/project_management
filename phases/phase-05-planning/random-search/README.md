# P5-07 — Случайные варианты и выбор итогового расписания

В дополнение к 12 детерминированным эвристикам проверяются **5000 случайно сгенерированных порядков приоритета** с фиксированным seed.

Лучший случайный вариант также дал **89 рабочих дней** и не улучшил лучший детерминированный результат.

Поэтому итоговым принимается расписание **FREE = 89 рабочих дней**: оно достигает лучшего найденного makespan и полностью воспроизводимо без случайного выбора.
