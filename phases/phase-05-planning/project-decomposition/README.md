# P5-01 — Декомпозиция реализации проекта

Выбранный вариант — сценарий A Фазы 3: 9 Use Cases, ориентировочно **1584 чел.-ч**.

Реализация разбита на **22 укрупнённые работы**. Детальная таблица находится в [tasks.csv](tasks.csv).

| Блок | Работы |
|---|---|
| Анализ и проектирование | T01–T04 |
| Инфраструктура | T05 |
| Разработка | T06–T17 |
| Безопасность | T18 |
| Тестирование | T19–T20 |
| Стабилизация и релиз | T21–T22 |

Декомпозиция сохраняет основные функции MVP: проекты тестирования, scope/активы, находки, доказательства, назначение ответственных, поиск/фильтрацию, формирование отчёта и управление пользователями/ролями.
