# P5-05 — Детерминированные эвристики

Для построения ресурсно-ограниченного расписания используется serial schedule generation scheme: готовые к запуску работы сортируются по правилу приоритета, после чего для выбранной работы ищется первый интервал, где одновременно доступны все требуемые ресурсы.

Проверены правила:

SLK, FREE, LST, LFT, LSTLFT, GRPW, LPT, MIS, GRD, GRWC, GCRWC, ROT.

| Эвристика | Makespan, раб. дней |
|---|---:|
| SLK | 96 |
| **FREE** | **89** |
| **LST** | **89** |
| LFT | 95 |
| **LSTLFT** | **89** |
| GRPW | 98 |
| LPT | 98 |
| MIS | 98 |
| GRD | 98 |
| GRWC | 98 |
| GCRWC | 98 |
| ROT | 90 |

Лучший детерминированный результат — **89 рабочих дней**.
