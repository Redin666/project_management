# P5-04 — Связи предшествования

Связи заданы в колонке `predecessors` файла [tasks.csv](../project-decomposition/tasks.csv).

Ключевые цепочки:

- T01 → T02/T03/T04;
- T02 + T03 → T06;
- T02 → T08/T09/T10/T12;
- T10 → T14 → T16;
- T06 + T16 → T18;
- завершение функциональных модулей → T19;
- T18 + T19 → T20;
- T19 + T20 → T21;
- T05 + T21 → T22.

Сеть ациклична. Без ресурсных ограничений критический путь даёт нижнюю границу **79 рабочих дней**; после учёта ограниченности специалистов срок увеличивается.
