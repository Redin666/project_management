# P5-02 — Состав команды и типы ресурсов

Ресурсная модель основана на результате P3-07: **4 FTE**.

| Тип ресурса | Количество | Основная зона ответственности |
|---|---:|---|
| Backend | **2** | API, БД, RBAC, находки, доказательства, отчётность, безопасность |
| Frontend | **1** | UI, формы, поиск, представление находок и отчётов |
| QA / DevOps / аналитика | **1** | требования, CI/CD, тестирование, развёртывание, приёмка |

Ресурсы считаются возобновляемыми: каждый рабочий день доступно 2 Backend, 1 Frontend и 1 QA/DevOps.
