# P5-10 — Итоговые выводы

1. Проект декомпозирован на **22 укрупнённые работы**, что соответствует требованию 20–25 задач.
2. Ресурсная модель использует **4 FTE**: Backend ×2, Frontend ×1, QA/DevOps/аналитика ×1.
3. Трудоёмкость плана составляет **1584 чел.-ч**, что согласуется со сценарием A Фазы 3.
4. Сетевой график без ограничений ресурсов даёт нижнюю границу **79 рабочих дней**.
5. После учёта ограничений ресурсов лучший найденный makespan — **89 рабочих дней**.
6. FREE, LST и LSTLFT дали одинаковый лучший детерминированный результат; 5000 случайных приоритетов его не улучшили.
7. При старте 23.11.2026 календарный срок проекта — до **25.03.2027**, около **17,8 рабочей недели**.
8. В Фазе 3 сценарий A оценивался примерно в **16,27 недели** для 4 FTE. Детальное ресурсное планирование увеличило срок примерно на **1,5 недели**, поскольку учитывает последовательность работ и локальные конфликты ресурсов.

Итоговый план подтверждает порядок величины оценки Фазы 3, но даёт более реалистичный календарный срок за счёт явного учёта предшествования и ограниченности специалистов.
