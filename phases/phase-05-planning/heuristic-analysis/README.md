# P5-06 — Анализ детерминированных эвристик

Лучший результат показали **FREE, LST и LSTLFT — 89 рабочих дней**. ROT дал близкий результат — 90 дней.

Наименее удачные правила для данной сети — GRPW, LPT, MIS, GRD, GRWC и GCRWC: **98 дней**. Причина в том, что приоритет крупных или ресурсоёмких работ сам по себе не учитывает, где возникает дефицит двух Backend-специалистов и как ранний запуск одной крупной работы может отложить другую ветвь.

FREE/LST/LSTLFT лучше согласуют порядок с сетевыми резервами и в данной структуре уменьшают простой последующих работ.
