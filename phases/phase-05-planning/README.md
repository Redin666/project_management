## Модель проекта

Реализация декомпозирована на **22 работы**.

Ресурсы:
- Backend — 2;
- Frontend — 1;
- QA / DevOps / аналитика — 1.

Суммарная ресурсная трудоёмкость: **198 человеко-дней = 1584 человеко-часа**.

## Результаты эвристик

Лучшие детерминированные правила:

- FREE — 89 раб. дней;
- LST — 89 раб. дней;
- LSTLFT — 89 раб. дней.

Лучший из 5000 случайных порядков также дал **89 дней**, поэтому итоговым выбрано воспроизводимое расписание FREE.

Без ресурсных ограничений нижняя граница по сети — **79 рабочих дней**.
