# Фаза 5 — Планирование

![Прогресс](https://img.shields.io/badge/Прогресс-0%25-lightgrey)

## Цель

Построить план реализации выбранного проекта с учётом ресурсов, зависимостей и рабочего календаря.

## Что нужно сделать

- декомпозировать реализацию проекта примерно на 20–25 задач;
- определить состав команды по специальностям;
- для каждой задачи задать потребность в ресурсах;
- указать связи предшествования;
- решить задачу расписания несколькими эвристическими методами;
- дополнить набор случайно сгенерированными вариантами;
- выбрать лучшее найденное решение;
- перенести его на 8-часовой рабочий день и 40-часовую рабочую неделю;
- определить плановые сроки проекта и отдельных этапов.

## Результаты фазы

- перечень работ;
- ресурсная модель;
- зависимости;
- результаты эвристик;
- выбранное расписание;
- календарный план проекта.
