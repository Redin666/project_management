# P5-03 — Ресурсные требования

Требования заданы непосредственно в [tasks.csv](../project-decomposition/tasks.csv) колонками:

- `backend`;
- `frontend`;
- `qa_devops`.

Суммарная ресурсная трудоёмкость:

`Σ duration × (backend + frontend + qa_devops) = 198 человеко-дней`.

При 8-часовом рабочем дне:

**198 × 8 = 1584 человеко-часа**.

Это значение совпадает с оценкой сценария A, принятого в P3-08.
