# Задание 1 — сценарии использования

## Цель

Подготовить UML-модель выбранного программного проекта для последующих заданий.

## Необходимо выполнить

1. Уточнить концепцию и границы MVP.
2. Определить акторов.
3. Составить список из примерно 10–15 основных Use Cases.
4. Построить общую Use Case Diagram.
5. Для каждого Use Case построить отдельную Activity Diagram.
6. На Activity Diagram обязательно использовать **swimlanes** для разделения действий разных акторов/объектов.
7. Проверить согласованность диаграмм и сохранить исходники/экспортированные изображения в репозитории.

## Рекомендуемая структура результатов

```text
docs/assignment-01-uml/
├── README.md
├── use-cases.md
├── use-case-diagram/
└── activity-diagrams/
```
