# Матрица RACI

Матрица актуализируется после каждого этапа проекта.

Обозначения:
- **R (Responsible)** — выполняет работу;
- **A (Accountable)** — отвечает за итоговый результат;
- **C (Consulted)** — консультирует;
- **I (Informed)** — информируется.

## Фаза 1 — Выбор концепции проекта

| Работа | Никита Редин | Павел Шатков | Владислав Полищук |
|---|---|---|---|
| Организация репозитория и таск-трекера | R/A | C | I |
| Стартовый митинг команды | R/A | R | R |
| Формирование 4 концепций | R/A | C | C |
| Формирование критериев | C | R/A | C |
| Экспертное оценивание | R | R | R |
| Нечёткий коллективный TOPSIS | R/A | C | I |
| Чёткий коллективный МАИ | C | R/A | I |
| Сравнение результатов и итоговый выбор | C | C | R/A |
| Актуализация RACI и оформление результатов | C | C | R/A |

## Принцип распределения

Работы распределены так, чтобы каждый участник отвечал за отдельный крупный блок Фазы 1:

- **Никита Редин** — формирование концепций и расчёт TOPSIS;
- **Павел Шатков** — формирование критериев и расчёт МАИ;
- **Владислав Полищук** — сравнительный анализ, итоговый выбор и оформление результатов;
- **экспертное оценивание** выполняют все три участника независимо.
